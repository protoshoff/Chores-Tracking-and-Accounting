QUEST TRACKER

Quick Start Guide

A chore tracking & allowance system for families.
Set up quests, track progress, and pay allowances — all from your kiosk.

Version 1.0  •  February 2026

📦 What You Need

Quest Tracker runs on a Raspberry Pi with a touchscreen. Before you start, make sure you have:

  • Raspberry Pi (3B or 4B) with power supply
  • Touchscreen LCD (7" or similar, connected to Pi)
  • MicroSD card with the Quest Tracker image pre-installed
  • Wi-Fi network (the Pi connects over your home Wi-Fi)

⚡ First Boot

Step 1 — Power On
Plug in the power supply. The Pi will boot and the Quest Tracker kiosk will appear automatically after about 30–60 seconds.
Step 2 — Connect to Wi-Fi (if needed)
If the kiosk shows "CONNECTING..." and doesn't load, you may need to configure Wi-Fi:
  1. Tap SYSTEM CONFIG (bottom-right of home screen)
  2. Enter the parent PIN (default: 1234)
  3. Tap WI-FI
  4. Select your network and enter the password
  5. Wait for the connection to establish, then go back to the home screen
⚠️ Change Your PIN! The default parent PIN is 1234. Change it right away under System Config → Configure System → Update Parent PIN.

👨‍👩‍👧‍👦 Adding Your Kids (Crew Members)

Step 3 — Open Crew Management
  1. Tap SYSTEM CONFIG → enter your PIN
  2. Tap MANAGE CREW
  3. Tap + NEW RECORD
Step 4 — Create Each Kid's Profile
  1. Enter their name
  2. Enter their weekly allowance amount (e.g., 10.00 for $10/week)
  3. Tap CREATE RECORD
  4. Repeat for each child (supports up to 10)
💡 Avatars: After creating a kid, tap their card on the home screen to open their dashboard. From there you can pick a fun sci-fi avatar (robot, rocket, shield, and more).

⚔️ Creating Quests (Chores)

Quests are the chores your kids need to complete to earn their allowance.

Step 5 — Open Quest Manager
  1. Tap SYSTEM CONFIG → enter your PIN
  2. Tap MANAGE QUESTS
  3. Tap + NEW QUEST
Step 6 — Set Up a Quest
  1. Assign to: Pick which kid this quest is for
  2. Name: Give it a clear name (e.g., "Dishes", "Clean Room")
  3. Description: Optional details about what's expected
  4. Frequency:
    • Daily — must be done every day
    • Weekly — must be done once a week on a specific day
  5. Tap SAVE QUEST

🔄 Rotation Quests (Shared Chores)

For chores that kids take turns doing (like taking out the trash):

Step 7 — Create a Rotation
  1. In Quest Manager, tap NEW ROTATION
  2. Enter the quest name and description
  3. Choose a rotation type:
TypeHow It Works
Alternating DailyDue every day — kids take turns (Kid A today, Kid B tomorrow…)
Every Other DayDue every other day — kids rotate on active days. Off days, nobody does it.
BiweeklyDue every 2 weeks on the same day of the week.
  1. Select which kids participate (check their names)
  2. The order you check them sets the rotation order
  3. Tap SAVE QUEST

📱 Daily Use — How It Works

For Kids

1. Tap your card on the home screen to open your dashboard.

2. Complete a quest — tap COMPLETE next to the chore you finished.

3. Wait for approval — the quest shows as "PENDING" until a parent reviews it.

Home Screen Cards show:
• Kid's name and avatar
• Current balance
• Today's progress (e.g., 2/3)
• Weekly progress bar

For Parents

Approving Quests
  1. Tap PARENT ZONE (bottom-left of home screen)
  2. Enter your PIN
  3. You'll see all pending quests waiting for review
  4. Tap APPROVE or REJECT for each one
💡 Tip: Only approved quests count toward the weekly allowance. Rejected quests don't count but can be re-submitted.

💰 Allowance & Payouts

Quest Tracker automatically calculates allowances each week based on quest completion. There are two payout modes:

ModeHow It WorksBest For
All-or-Nothing Kids must complete a minimum percentage of quests (default: 80%) to earn their full allowance. Below the threshold = $0. Families who want strong motivation
Proportional Kids earn a percentage of their allowance equal to the percentage of quests completed. 60% done = 60% of allowance. Families who want gradual rewards
Configure Payout Mode
SYSTEM CONFIG → PIN → CONFIGURE SYSTEM → choose your mode and threshold.

Payouts happen automatically every Sunday at midnight. The earned amount is added to each kid's balance, visible on their home screen card.

Managing Balances

To pay out cash or make adjustments:

  1. Go to SYSTEM CONFIG → LEDGER
  2. Select a crew member
  3. PAYOUT ALL — resets their balance to $0 (when you hand them cash)
  4. ADJUST (+/-) — add a bonus or subtract a penalty

🌐 Web Admin Portal (Remote Access)

You can manage everything from your phone or computer — no need to walk to the kiosk!

Accessing the Web Portal
  1. Make sure your phone/computer is on the same Wi-Fi network as the kiosk
  2. Open a web browser and go to: http://<kiosk-ip-address>:8000/admin
  3. To find the kiosk's IP address: SYSTEM CONFIG → the IP is shown on the settings screen

The web portal has full feature parity with the kiosk — you can:

  • Add and edit crew members (with avatars)
  • Create and manage quests and rotation quests
  • Approve or reject pending quests
  • View and manage the ledger
  • Configure payout settings
💡 Bookmark it! Save the admin URL on your phone's home screen for quick access.

🔄 Updating the Kiosk

Check for Updates
  1. Tap SYSTEM CONFIG → enter your PIN
  2. Tap CHECK FOR UPDATES
  3. If an update is available, it will download and install automatically
  4. The kiosk will reboot when the update is complete

Updates preserve all your data (kids, quests, balances, history).
